# Sprout 2.0 — UI/UX Case Study

A mobile-first investing experience designed for first-time investors in India.

## Project Overview
Sprout helps beginner investors understand the onboarding process, prepare their documents, and navigate identity verification.

## Design Deliverables
- Mobile homepage
- Desktop homepage
- Five mobile onboarding screens
- Sprout mascot sheet
- Design system and accessibility guide
- Clickable Figma prototype
